## 🛠️ How to Convert to PDF / Word

**Option 1 — VS Code:**
1. Open any `.md` file in VS Code
2. Install extension: "Markdown PDF" (by yzane)
3. Right-click → "Markdown PDF: Export (pdf)"

**Option 2 — Pandoc:**
```bash
pandoc 08_Project_Report_Final.md -o Project_Report.pdf --pdf-engine=xelatex
```

**Option 3 — Online:**
1. Copy content from `.md` file
2. Paste at: https://dillinger.io or https://stackedit.io
3. Export as PDF
